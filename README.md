# YatraVerse

**Discover the Soul of India** — AI-powered tourism discovery, travel planning & experience ecosystem.

## Tech Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS
- Framer Motion
- GSAP (available for extended animations)
- Lucide React icons
- Swiper.js carousels

## Pages

| Route | Page |
|-------|------|
| `/` | Home — cinematic hero, features, trending destinations |
| `/discover` | Discover India — filters, interactive map |
| `/destinations` | Destination showcase |
| `/destinations/[id]` | Destination detail |
| `/ai-planner` | AI Trip Planner dashboard |
| `/yatrago` | YatraGo mobility (black & gold) |
| `/packages` | Tour packages |
| `/booking` | Booking platform |
| `/blog` | Travel stories |
| `/dashboard` | User dashboard |
| `/about` | About Us |
| `/contact` | Contact |
| `/login` | Login / Signup |

## Connect with Expert

Available in the navbar on all pages — language dropdown + Call Expert with success notification.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
